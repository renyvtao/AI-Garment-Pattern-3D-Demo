# 男西装 LoRA v1 留出集结果

评测日期：2026-08-18。测试集按基础款分组划分，包含 72 个未参与训练的基础款、
216 张图片。官方基础权重和“官方基础权重 + 男西装 LoRA”使用相同图片、提示词
和解码设置；LoRA 结果还逐例执行参数适配与二维板片生成。

## 总体结果

| 模型 | 生成成功 | 目标结构解析成功 | 六字段完整 | 常规六字段宏平均 | 平衡六字段宏平均 | 全字段同时通过 | 板片生成 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 官方基础权重 | 100.00% | 0.00% | 0.00% | 不适用 | 不适用 | 不适用 | 未执行 |
| 官方基础权重 + 西装 LoRA | 100.00% | 100.00% | 100.00% | 78.86% | 45.11% | 16.67% | 100.00% |
| 测试集多数类常量基线 | 不适用 | 不适用 | 不适用 | 78.47% | 44.44% | 16.20% | 不适用 |

官方基础权重可以生成文本，但输出的是原 ChatGarment 通用服装结构，不含本次
西装适配器要求的六个字段。因此其 0% 表示“不能直接进入男西装参数通路”，
不表示基础模型完全不能生成其他服装。由于输出空间不同，基础权重的六字段准确率
记为“不适用”，而不是把它错误解释成六个字段全部预测错误。

## 指标含义与评测意义

| 指标 | 如何计算 | 评测意义 |
|---|---|---|
| 生成成功率 | 完成一次模型解码且产生非空输出的样本比例 | 判断模型和推理环境能否稳定运行；成功不代表内容正确。 |
| 目标结构解析成功率 | 输出能够被解析成西装六字段目标结构的比例 | 衡量模型是否遵守约定的结构化输出协议，是进入后续适配器的前提。 |
| 六字段完整率 | 六个监督字段全部存在且类型合法的样本比例 | 衡量结构完整性；不检查字段值是否正确。 |
| 常规六字段宏平均 | 先计算每个字段的样本通过率，再对六个字段等权平均 | 反映总体字段命中情况，但标签不均衡时可能被多数类抬高。 |
| 平衡六字段宏平均 | 每个字段先对各取值的召回率等权平均，再对六字段等权平均 | 降低类别数量不均衡的影响，是当前数据上判断模型是否真正识别图片属性的主要指标。随机或只猜单一类别时通常接近较低水平。 |
| 全字段同时通过率 | 单张图片的六个字段全部通过才计为成功 | 衡量一个样本能否无需人工修正地完整进入参数化制版，要求最严格。 |
| 多数类常量基线 | 不读取图片，每个字段永远输出测试集中最常见的值 | 检查高准确率是否只是利用标签分布；LoRA 若未明显超过该基线，说明图像条件学习较弱。 |
| MAE | 连续字段预测值与真值绝对误差的平均值 | 直观表示平均偏差大小，越低越好。 |
| RMSE | 连续字段平方误差均值的平方根 | 对少数较大误差更敏感，用于发现严重偏差，越低越好。 |
| 类别召回率 | 某一真实取值被正确识别的比例 | 揭示少数类是否完全漏识别，避免总体准确率掩盖类别塌缩。 |
| 板片生成成功率 | 预测参数经规则适配后能生成二维规格和板片的比例 | 衡量模型输出对下游制版程序的工程可用性，不等同于板片尺寸正确率。 |

## 字段结果

连续字段容差为 `garment_length_ratio ≤ 0.01`、`waist_ease_cm ≤ 0.5 cm`；
其他字段严格相等。

| 字段 | 常规通过率 | 平衡通过率 | 多数类常量基线 | MAE | RMSE | 关键现象 |
|---|---:|---:|---:|---:|---:|---|
| `garment_length_ratio` | 94.91% | 33.33% | 94.91% | 0.0018 | 0.0079 | 只识别主流值 1.75，另外两个取值召回率为 0% |
| `waist_ease_cm` | 89.81% | 33.33% | 89.81% | 0.2801 cm | 0.8776 cm | 只识别主流值 15.0，另外两个取值召回率为 0% |
| `lapel_style` | 89.81% | 50.00% | 89.81% | — | — | `notched` 召回 100%，`peak` 召回 0% |
| `button_count` | 59.72% | 53.98% | 57.41% | — | — | 1 粒扣召回 15.22%，2 粒扣召回 92.74% |
| `small_pocket_enabled` | 56.48% | 50.00% | 56.48% | — | — | `false` 召回 100%，`true` 召回 0% |
| `large_pockets_enabled` | 82.41% | 50.00% | 82.41% | — | — | `false` 召回 0%，`true` 召回 100% |

多数类常量基线不读取图片，只固定输出各字段在测试集中出现最多的值。LoRA 的
常规六字段宏平均为 78.86%，多数类基线为 78.47%，只提高 0.39 个百分点；
全字段同时通过率分别为 16.67% 和 16.20%，只提高 0.46 个百分点。

## 与 ChatGarment 原论文结果的对照

[ChatGarment 原论文](https://arxiv.org/abs/2412.17811)没有报告 JSON 解析率、
字段准确率、平衡准确率、类别召回率、参数 MAE 或 RMSE。论文把预测配置转换、
缝合并放置到三维人体后，再用三维表面指标衡量最终服装重建；文本生成任务还要
渲染生成服装后计算 CLIP Score。因此，论文数值与本次六字段模型评测不存在可直接
换算的同口径指标，不能把 `45.11%` 与论文的 `0.790` 等数值作高低排名。

| 能力维度 | 原论文原始测试集结果 | 本次西装 LoRA 结果 | 可否直接比较 |
|---|---|---|---|
| 结构化输出协议 | 未报告 JSON 解析率或字段完整率 | 解析成功 100.00%，六字段完整 100.00% | 否；论文未给同项指标 |
| 图像条件参数识别 | 未报告参数级真值准确率、MAE 或 RMSE | 常规宏平均 78.86%，平衡宏平均 45.11%，全字段同时通过 16.67% | 否；这是本项目新增指标 |
| 多数类偏置 | 未报告多数类基线或逐类别召回率 | 多数类宏平均 78.47%，LoRA 仅高 0.39 个百分点 | 否；论文没有对应统计 |
| 输出可缝合性 | Dress4D 与 CLoSE 的 stitching failure rate 均为 0% | 216/216 完成 K62/Warp 缝合，失败率 0.00% | 仅可比较指标方向；测试集和装配拓扑不同 |
| 文本提示对齐 | 150 条文本提示上的 CLIP Score 为 23.7 | 未执行文本生成和渲染后 CLIP 评测 | 否；任务、输入和测量链路不同 |

为便于核对论文，下面保留其原始数值，但这些指标不进入本次“仅评估西装 LoRA
模型能力”的结论：

| 原论文任务与测试集 | ChatGarment 原论文结果 | 本次是否采用 |
|---|---|---|
| Dress4D 图像重建，Target-Pose | CD 3.12，F-Score 0.75，stitching failure rate 0% | 仅采用同名缝合失败率；本次为 0.00% |
| Dress4D 图像重建，A-Pose | CD 3.06，F-Score 0.78，stitching failure rate 0% | 仅采用同名缝合失败率；本次为 0.00% |
| CLoSE 图像重建 | CD 2.94，F-Score 0.790，stitching failure rate 0% | 仅采用同名缝合失败率；本次为 0.00% |
| 135 对服装编辑样本 | CD 2.51，F-Score 0.893 | 不采用；属于三维几何编辑结果 |
| 150 条文本生成提示 | CLIP Score 23.7 | 不采用；依赖生成服装的渲染图像 |

其中 CD 衡量预测与真值三维服装表面的平均距离，越低越好；F-Score 在论文设定的
距离阈值 `τ = 0.001` 下综合衡量表面点的精确率与召回率，越高越好；stitching
failure rate 是无法得到有效缝合服装的样本比例，越低越好；CLIP Score 衡量渲染
图像与文本提示的语义一致性，越高越好。它们分别受到三维人体拟合、制版解码、
缝合、垂坠或渲染环节影响，不是 VLM/LoRA 六字段预测的纯模型指标。

本次缝合评测把每个 LoRA 预测转换为 K62 规格，执行网格构建、Warp 缝合/垂坠并
检查最终服装网格导出。216 个样本全部完成，未使用渲染图或视频打分。由于 K62
使用固定 11 片、66 条基础缝合拓扑，0% 证明通路稳定，但不能证明预测尺寸、驳领、
口袋等属性正确。

CD 和 F-Score 不能用预测网格相互比较来替代真值。继续实现需要逐图片真实西装
三维网格、准确 SMPL-X 注册/姿态以及统一坐标和单位；这些数据当前不存在。

## 结论

第一版微调已经验证完整技术通路：LoRA 能稳定输出西装字段，解析和字段完整率均为
100%，216 个样本均成功生成二维板片并完成 K62/Warp 缝合。因此它适合作为
“男西装 LoRA 可接入现有 GarmentCode/K62 流程”的概念验证。

但它尚未学到可靠的图像条件属性识别。除纽扣数存在少量区分能力外，其余五个字段
基本退化为多数类模板；78.86% 的常规准确率主要来自测试标签不平衡，不能作为生产
可用性的依据。下一版应优先平衡各参数组合、增加少数类和真实图片、按基础款继续
分组划分，并以平衡准确率、各类别召回率和外部测试集结果作为主要指标。
